# Braid–Quantum–Lorentz Unification Preprint v0.1

This directory preserves the public source, exact reviewed PDF, metadata, and
verification materials for:

> Satoru Watanabe, *Subjectivity Intersection Mathematics: A Common
> Pointed-Braid Source for Quantum History and Lorentzian Geometry*, v0.1
> (2026).

The result is a conditional, fixed-finite, local short-time composition
theorem. It does not establish an empirically validated theory of quantum
gravity, absolute semiclassical gravity, or an ontological theory of
subjectivity.

## Files

- `BRAID_QUANTUM_LORENTZ_UNIFICATION_PREPRINT_v0.1.tex`: reviewed authoring
  source frozen for v0.1.
- `Braid_Quantum_Lorentz_Unification_Preprint_v0.1.pdf`: exact reviewed
  14-page public preprint.
- `ARTIFACT_MANIFEST_v0.1.json`: file identities and release scope.
- `ZENODO_METADATA_v0.1.json`: metadata frozen for a later Zenodo deposit.
- `INTELLECTUAL_PROVENANCE_LEDGER_v0.1.json`: intellectual provenance and
  claim-boundary record.
- `PUBLIC_VERIFICATION_NOTES.md`: public verification summary and claim
  boundary.
- `verify_release.py`: local integrity and claim-boundary verification.
