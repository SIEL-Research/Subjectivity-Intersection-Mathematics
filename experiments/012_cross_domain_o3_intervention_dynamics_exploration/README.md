# E012 local exploration — cross-domain O3 intervention dynamics

Status: `LOCAL_RESULT_INFORMED_EXPLORATION`

This exploration asks a stronger cross-domain question than E011:

> Do independently executed atomic, molecular, and cellular models exhibit the
> same causal O3 intervention signature without receiving a shared scalar
> mediator or a common encoded bridge law?

The shared signature is fixed at the intervention level:

1. intact O3 supports whole formation;
2. removing O3 lowers whole formation;
3. a mismatched return does not substitute for the registered O3;
4. correct return restores whole formation.

The three engines remain domain-specific.

- **Atomic:** open two-body soft-Coulomb quantum relaxation for the E008
  muonium and positronium reduced masses. The interaction is retained, removed,
  returned at the wrong centre, or correctly returned.
- **Molecular:** discrete relaxation on the three independently computed E010
  `H4+` energy surfaces. The complete surface, one-electron carrier deletion,
  single-edge return, and complete return are compared.
- **Cellular:** new exploratory seeds in the E009 reduced stochastic dynamics
  under native, joint-erased, time-shifted, and reinjected conditions.

No atomic, molecular, or cellular state receives the post-hoc common whole
score. Cross-domain comparison occurs only after each engine has produced its
own domain readout. This preserves the compression ladder:

```text
domain source -> domain dynamics -> domain whole readout -> causal signature
```

The exploration includes leave-one-domain-out signature transfer and an exact
condition-label permutation null. Its thresholds were selected after component
feasibility checks and therefore cannot be treated as preregistered or
confirmatory evidence.

Run locally:

```bash
python3 experiments/012_cross_domain_o3_intervention_dynamics_exploration/run.py
```

Results are written under `results/`. Nothing in this directory is registered,
released, or claimed as evidence in living cells or natural cross-domain
physics.
