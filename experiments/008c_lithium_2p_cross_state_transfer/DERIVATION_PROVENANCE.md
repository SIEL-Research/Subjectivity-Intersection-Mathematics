## Chronology disclosure

The E008B lithium `2S_1/2` observation was known before CP-158. CP-158's
`73.0408505 ppm` recursive correction therefore constitutes post-hoc lithium
discovery material, not an independent prediction. The same frozen formula
failed the already available E008A H/D portability audit.

E008C does not erase either fact. It freezes the formula unchanged and tests
whether it transfers to a distinct lithium electronic state whose reported
hyperfine constants and uncertainties have not been loaded into this package.

## Target-value separation

The metadata screen used only bibliographic fields sufficient to identify a
paper containing both isotopes and the `2^2P_1/2` level. No reported target
constant or uncertainty was transcribed. Target extraction is forbidden until
the public registration objects are verified.
