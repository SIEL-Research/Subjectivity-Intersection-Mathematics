# Experiment 013 preregistration readiness

Status: `READY_TO_DRAFT_AND_REGISTER; NOT YET CONFIRMATORY`

## Claim placed at risk

Given only a domain bridge and before assigning an O3 label, the same residual
construction identifies a candidate relation whose complete removal and
structurally mismatched return impair whole-formation, while its correct return
restores it:

```text
R*_D = P_loc,D(G_D)
C*_D = G_D - R*_D
G_removed,D = R*_D
G_correct,D = R*_D + C*_D = G_D
```

This is a prospective cross-domain test of a common generation-and-intervention
grammar. It is not a claim that the three domain carriers are physically or
numerically identical.

## Items ready to freeze

1. Domain inputs are fixed before outcomes: local terms, native generator,
   units, boundary conditions, admissible transformations, and causal readout.
2. `P_loc,D` is the maximal local-preserving severing projection.
3. The O3 candidate is generated only as `G_D - P_loc,D(G_D)`.
4. Complete removal must return exactly to the reference; correct return must
   reconstruct the native generator to registered numerical tolerance.
5. Mismatch is the minimal admissible isometry outside the correct-return
   equivalence class with centered candidate overlap at most `0.25`.
6. The cross-domain topology contains only four preregistered inequalities:
   `intact > removed`, `intact > mismatch`, `correct > removed`, and
   `correct > mismatch`.
7. The unrestricted removal-versus-mismatch ordering is retained as a
   diagnostic and cannot alter the primary decision.
8. Leave-one-domain-out must be computed from held-out outcomes, never copied
   from per-domain pass flags.
