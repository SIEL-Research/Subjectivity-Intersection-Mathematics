# Domain-prior O3 generation and mismatch rules

Status: `LOCAL_EXPLORATORY_FORMALIZATION`

## Inputs supplied by a domain bridge

Before whole-formation outcomes are inspected, a bridge must specify:

1. differentiated local terms and their native state coordinates;
2. the native generator `G_D`;
3. local units, boundary conditions, and admissible transformations;
4. the native coordinate along which generated relation re-entry is registered.

These inputs describe the domain. They do not identify O3.

## Reference-generation rule

Let `P_loc,D` be the maximal local-preserving severing projection. It preserves
the local terms, their unary laws, units, and boundary conditions while replacing
joint dependence by the pointwise-minimal admissible construction having the
same registered local boundary marginals.

```text
R*_D = P_loc,D(G_D)
C*_D = G_D - R*_D
```

The candidate O3 is therefore generated by one residual rule after the domain
structure is supplied. It is not selected from a list of successful carriers.

Realizations used in this exploration:

- atomic: preserve relative kinetic propagation and sever the attractive
  relational potential;
- molecular: preserve the direct sum of isolated-centre generators and sever
  all molecule-minus-isolated-centres sectors;
- cellular: preserve each local variable and unary boundary marginal while
  replacing a bilinear joint gate by its pointwise-minimal inclusion-exclusion
  gate `max(0, x + y - 1)`.

## Removal and correct return

```text
G_removed,D = G_D - C*_D = R*_D
G_correct,D = R*_D + C*_D = G_D
```

Both identities must reconstruct to numerical tolerance before outcome gates
are evaluated.

## Mismatch-admissibility rule

A mismatch is generated rather than selected:

```text
C_mismatch,D = tau_D(C*_D)
```

`tau_D` must be fixed before outcomes and must:

1. preserve the candidate's value multiset or registered strength;
2. leave `R*_D`, the local state, and the update law unchanged;
3. remove invariant offsets, then choose the smallest admissible isometry whose
   centered candidate self-overlap is at most `0.25`;
4. lie outside the registered equivalence/symmetry class of correct return.

The `0.25` threshold is result-informed by this exploration and can become
confirmatory only after prospective registration. Constant energy or coordinate
offsets are removed before overlap because they are representation gauges, not
O3 identity. The same rule selects approximately `8.40` spatial units in the
atomic potential, `0.5 Å` along the molecular geometry grid, and `6 minutes` in
the cellular relation trajectory.

## Cross-domain causal partial order

The transferable O3 claim fixes only the four relations required by removal,
mismatch, and specific return:

```text
intact > removed
intact > mismatched return
correct return > removed
correct return > mismatched return
```

It does not predict whether complete removal must score above or below a
mismatched return. That extra comparison is reported as an unrestricted
learned-pairwise diagnostic, not promoted to a constitutive gate.

## Evidential boundary

These rules are result-informed exploratory formalizations. Passing them may
justify a later preregistration but is not itself confirmatory evidence.
The exploration does not prove that `P_loc,D` is the unique possible severing
projection for every domain decomposition. A confirmatory registration must
freeze the local partition, projection construction, and equivalence class
before held-out domains and outcomes are executed.
