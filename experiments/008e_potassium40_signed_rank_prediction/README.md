# Experiment 008E

E008E freezes a new K-40 numerical prediction generated by the signed,
rank-separated potassium connection recovered in CP-162.

The primary target is the leading complete second-order correction to
`A(4P_1/2)` for neutral K-40. The generator contains no K-40 correction value,
`eta`, or `zeta` benchmark and has no fitted coefficient.

The registered central prediction is

`delta A(4P_1/2; K-40) = 0.008107082333170607 kHz`,

with input envelope `[0.007968190838682242, 0.008247506485579788] kHz`.

## Registration state

`PREREGISTERED_NOT_EXECUTED`

`e008e-preregistration-v1.0.0`, public Release, and DOI verification.

```bash
python3 experiments/008e_potassium40_signed_rank_prediction/run.py \
  --validate-registration
```

```bash
python3 experiments/008e_potassium40_signed_rank_prediction/generate_prediction.py \
  --output /tmp/e008e-prediction.json
```

Do not search for a K-40 second-order correction before the public DOI is
verified.
