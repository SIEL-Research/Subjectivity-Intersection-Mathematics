# Technical Specification

## Input validation

The runner verifies the Phase 1 candidate-table and summary hashes before loading candidates. Candidate IDs, operation steps, inverse relations, Lagrange flags, source-anchor fields, and selection fields must match the Phase 1 schema.

The runner also verifies the frozen D12RG Riemann Git commit, origin remote, clean worktree, and required source hashes.

## Candidate representation

One candidate is represented by the primitive pair `(a,m)` in `C12 x C12`. The complete labelled mapping is `(a,-a,m,-m) mod 12` in the fixed operation order addition, subtraction, multiplication, division.

## C12 calculations

The order of one element `k` is `12 / gcd(12,k)`. The subgroup generated by `(a,m)` has order `12 / gcd(12,a,m)`.

All cumulative development paths start at zero and apply the labelled deck step modulo twelve.

## Moving-projector calculations

The frozen source-defined Paper 5.3 admissible mode set is translated separately by each labelled operation step. Union size and all six pairwise symmetric differences are computed as exact integer set operations.

## Ranking

The score is an exact tuple of integers and Booleans. Python tuple ordering is used only after the metric order has been constructed explicitly as registered. No floating-point quantity enters candidate ranking.

## Equivalence classes

The orbit of `(a,m)` contains all pairs produced by the four C12 units and optional primitive-label exchange. Duplicate orbit members are removed. The lexicographic minimum is the class key.

Equivalence-class summaries report member count, top-member count, and canonical candidate ID. A canonical representative is not interpreted as a uniquely discovered mathematical rule.

## DVJ calibration

The native source functions `solve_dvj_positive_roots`, `dvj_direct_transfer_symbol`, `dvj_reciprocal_phase_carrier`, `canonical_twisted_links`, and `twisted_cycle_power` are used without reimplementation.

## Failure behavior

The runner exits nonzero for registration mismatch, Phase 1 mismatch, source mismatch, malformed candidate family, failed exact metric invariant, failed DVJ calibration, or incomplete output writing.

It exits zero for any of the four registered primary classifications, including unresolved multiple equivalence classes.
