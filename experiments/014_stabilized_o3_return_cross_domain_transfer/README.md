# Experiment 014 — Stabilized O3 Return Cross-Domain Transfer

Status: `PREREGISTERED_NOT_EXECUTED`

This package prospectively tests a single cross-domain prediction on fresh
atomic, molecular, and cellular targets: after domain-native stabilization,
correct O3 return remains closer to the registered domain state than continued
removal or a physically distinguishable mismatched return.

Unlike E011, all three domains are executed as independent targets. No shared
mediator or scalar enters their dynamics. Unlike E013, the primary decision
does not impose one absolute score threshold across inequivalent domain
readouts.

The registration release and DOI must be public before the single target
execution. Until then only the following target-free validation is permitted:

```bash
python3 experiments/014_stabilized_o3_return_cross_domain_transfer/run.py \
  --validate-registration
```

See `PREREGISTRATION.md`, `TECHNICAL_SPECIFICATION.md`, and
`TARGET_PROVENANCE.md` for the frozen claim, gates, and source record.
