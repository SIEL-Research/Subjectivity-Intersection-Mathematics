# Experiment 014 technical specification

## Compression boundary

```text
domain source -> domain O3 carrier -> intervention history
              -> domain state distribution -> registered similarity
              -> sign of stabilized causal specificity
```

Inference stops at the final directional relation. Numerical agreement is not
used to infer common source construction or substance.

## Atomic bridge

The O3 carrier is the native-minus-free soft-Coulomb potential. Complete
removal replaces it with the free reference; correct return restores the
native potential; mismatch returns the same attraction around a centre shifted
by 8 coordinate units without periodic wraparound. The readout is Hellinger
similarity of the full normalized density to matched intact dynamics at equal
total time. Primary return checkpoints are 200, 400, and 800 steps.

## Molecular bridge

At 13 geometries the runner constructs the full and isolated-centre cc-pVTZ
FCI generators using the frozen E010 implementation. Their pointwise
difference is the molecular O3 carrier. Exact Metropolis transition matrices
propagate the intact, removed, correct-return, and mismatched-return
distributions. Hellinger similarity to matched intact dynamics is evaluated at
100, 200, and 400 base return steps for grid factors 1, 2, and 4. All time
windows scale by the square of the grid factor.

## Cellular bridge

The unchanged E009 dynamics supplies native, joint-erased, time-shifted, and
reinjected conditions. The boundary prediction is evaluated separately from
stabilized specificity. The latter compares paired lineage fingerprints made
from the three module observables, damage divided by the E009 death scale, and
biomass. Its one-sided 99% bootstrap lower bounds use 20,000 frozen resamples.

## Provenance lock

`--validate-registration` verifies all registered source hashes without
running a target. `--execute` requires a receipt containing the full
preregistration commit, GitHub Release URL, tag, and Zenodo DOI. The results
directory must not exist. Molecular energies are checkpointed only after the
lock is satisfied so an interrupted calculation can resume without changing
the registered code or targets.
