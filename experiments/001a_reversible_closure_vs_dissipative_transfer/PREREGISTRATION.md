# Experiment 001A Preregistration

## Title

**Reversible Closure versus Dissipative Relational Transfer**

## Registration date

2026-07-30

## Registration status

Registered design — confirmatory execution pending.

This document becomes a frozen preregistration only when it is published in a
GitHub commit together with the executable implementation, tests, and a

## Purpose

Experiment 001 established an exact finite positive control in which two
overlapping involutions generate an `S3` interaction algebra and a `C3`-type
carrier under the registered balanced four-event histories. Experiment 001A
asks whether the standard full-adder carry process exhibits any comparable
history-bearing structure, or whether it is an irreversible control process
whose future behavior is fully reducible to its current carry state and
ordinary output buffering.

The experiment is a finite mathematical calibration. It does not test
subjectivity, Intersection Subjectivity, a physical CDC 6600 implementation,
or a biological system.

## Primary question

Does the standard kill/generate/propagate full-adder process retain a jointly
generated historical state that changes later role-indexed readouts after all
registered present-state controls have been matched, or is its behavior fully
explained by the current carry value, the most recent overwriting event, and
ordinary one-step output memory?

## Formal system

### Input alphabet

Each event is an ordered input pair

`x = (a, b)`, where `a, b` are in `{0, 1}`.

The registered alphabet is

`X = {00, 01, 10, 11}`.

The order of the two positions is retained throughout the audit. Exchanging
the positions is a registered role transformation, not a partner-substitution
test.

### Canonical full-adder transducer

The persistent state is the carry bit `c` in `{0, 1}`. For input `(a, b)`,
the next carry and emitted SUM bit are

`c_next = majority(a, b, c)`

and

`sum = a XOR b XOR c`.

The emitted transition readout is the ordered pair

`y = (sum, c_next)`.

Because the output depends on both the current state and the current input,
the canonical model is registered as a Mealy transducer. It must not be
described or minimized as a Moore automaton unless the output is explicitly
added to the persistent state.

### Induced carry actions

The four input symbols induce three maps on the carry state:

- `00` induces kill, `K(c) = 0`;
- `11` induces generate, `G(c) = 1`;
- `01` and `10` induce propagate, `P(c) = c`.

The transition monoid generated by `{K, G, P}` is audited exactly. The two
ordered mixed inputs remain separate symbols in the Mealy audit even though
they induce the same map on carry.

## Registered model layers

### F0 — carry-only control

Persistent state: `c`.

Transition readout: `(sum, c_next)`.

This is the canonical one-bit full-adder feedback model.

### F1 — explicit one-step output buffer

Persistent state: `(c, z)`, where `z` is the most recently emitted SUM bit.

After input `(a, b)`, the state becomes `(c_next, sum)`. The buffer is allowed
to distinguish current output records but does not feed back into the carry
transition unless a separate registered model explicitly states otherwise.

F1 is a matched ordinary-memory control. A distinction explained by `z` does
not count as a relational historical effect.

### E001 — frozen reversible positive control

The unchanged implementation and result from Experiment 001 provide the
positive control for exact path-order dependence, nontrivial bilateral probe
readout, and gauge-covariant `C3`-type carrier classification. Experiment 001A
must import or reproduce E001 only through files and digests frozen in the
registration manifest.

No auxiliary phase variable, relational trit, or additional carrier state may
be added to F0 or F1 after registration.

### GM — same-capacity generic-memory control

Persistent state: `(c, m)`, with the same four-state capacity as F1.

The carry follows the canonical full-adder transition, while
`m_next = a XOR b` stores only whether the latest input was mixed. This control
has no relational interpretation. It tests whether state capacity alone is
being mistaken for relational history.

## Registered hypotheses

### H0 — reducible overwrite-and-propagate control

For F0, every future output trace is determined completely by the current
carry and the future input word. Histories ending at the same carry are
behaviorally equivalent under every common future suffix. The current carry
is determined by the most recent `00` or `11` event, or by the initial carry
when no such event has occurred.

Under H0, role exchange `01 <-> 10` does not alter the canonical output trace,
and no pair-specific historical carrier is present.

### H1 — bounded dissipative memory without relational irreducibility

F1 retains distinctions absent from the carry-only projection, but every such
distinction is reproduced by the declared one-step SUM buffer or another
registered non-relational control. The system may support order-sensitive
state transfer, erasure, or overwriting without satisfying the criteria for a
history-bearing relational carrier.

### H2 — operational relational-carrier candidate

At least one registered witness satisfies all of the following conditions:

1. two histories have the same complete registered present signature;
2. a common future probe produces different output traces;
3. the difference is not reproduced by F0, F1, the latest-overwrite rule, or
   the registered local-history controls;
4. exchanging the two roles changes the effect in a way not explained by the
   symmetric full-adder equations;
5. a nontrivial pre-intervention bilateral structure is disrupted and later
   restored, rather than merely replacing one scalar carry value with another;
6. the classification survives the registered coordinate transformations.

H2 would establish only an operational finite-state carrier candidate under
the frozen tests. It would not establish subjectivity or an ontological third
term.

## Frozen null models

The confirmatory audit must compare the candidates with all of the following:

- current carry alone;
- initial carry plus the most recent non-propagate event (`00` or `11`);
- current carry plus the most recent complete input symbol;
- current carry plus the most recent SUM bit;
- the explicit F1 one-step output buffer;
- separate A-position and B-position event counts;
- separate A-position and B-position parity histories;
- a same-size generic finite-memory control with no relational interpretation;
- the exact role-symmetric full-adder equations; and
- the frozen Experiment 001 positive control.

Failure against one narrow null must not be described as relational
irreducibility.

## Exact audit procedures

### A1 — transition-monoid census

Enumerate every transformation of the declared F0 and F1 state spaces induced
by the four input symbols. Report the complete transition monoid, image sizes,
fixed points, absorbing maps, permutation elements, and composition table.

### A2 — exact behavioral minimization

Compute exact observational equivalence by partition refinement until
stability. F0 equivalence includes its declared carry observation. F1
equivalence includes the current buffered SUM observation as well as every
future Mealy output trace. Two states are equivalent only when their declared
current observations match and every possible common future input word
produces the same output trace.

This exact equivalence result is primary. Finite history enumeration is used
only to produce readable witnesses and receipts.

### A3 — history census

From both initial carry values, enumerate every input history of length zero
through eight. Record the final state, final emitted output, last input, most
recent kill/generate event, separate role histories, and complete output
trace.

Search exhaustively for pairs of histories that match the full registered
present signature but are separated by a common future suffix. Any reported
witness must include the complete pre-probe observation; matching only carry
and SUM while excluding declared readout channels is prohibited.

### A4 — latest-overwrite sufficiency

Test whether the final carry is exactly predicted by the most recent `00` or
`11` event, with the initial carry retained when the history contains only
propagate events. Report every exception. H0 requires zero exceptions.

### A5 — role-exchange audit

For every registered history, exchange `a` and `b` at every event and compare
the complete state and output traces. This tests role symmetry only. It must
not be reported as pair specificity because the canonical model contains no
identities for distinct A-B pairs.

### A6 — carry intervention and role-indexed probes

At every reachable state, intervene by setting or flipping the carry and then
apply the ordered probes `10` and `01`. Record both resulting output traces.

An intervention effect on both probes establishes that carry influences both
role-indexed readouts. Identical effects on the two probes do not establish
differentiated bilateral feedback or reconstitution of A and B.

### A7 — overwrite versus recovery

Audit excursions containing kill followed by generate and generate followed
by kill from every reachable F0 and F1 state.

Report three distinct endpoints:

- scalar return: the carry value equals its pre-excursion value;
- complete-state return: the full declared persistent state is behaviorally
  equivalent to its pre-excursion state;
- relational recovery: a nontrivial, pair-specific bilateral readout structure
  existed before the excursion, was disrupted, and the same structure was
  restored afterward.

Scalar return alone must be classified as value restoration or overwriting,
not relational recovery. Relational recovery cannot pass when the required
pre-excursion bilateral structure was never present.

### A8 — coordinate audit

Audit both relabelings of the binary carry domain. Under the nontrivial
relabeling, kill and generate exchange roles and propagate remains the
identity. Transform the transition and output definitions, decode the result,
and test exact commutation.

This is an implementation-level covariance check. It is not evidence of
physical gauge invariance or relational irreducibility.

### A9 — positive-control transfer

Apply the unchanged decision criteria, as far as their types permit, to the
frozen Experiment 001 positive control. The audit must preserve the distinction
between the `S3` interaction algebra and the `C3`-type carrier reached by the
balanced four-event histories.

Raw state counts or monoid orders are not sufficient for cross-model
classification.

## Primary endpoints

The primary endpoints are:

1. the number of exact behavioral equivalence classes in F0 and F1;
2. the number of full-present-matched history pairs separated by a common
   future suffix;
3. the number of violations of latest-overwrite sufficiency;
4. the number of role-exchange asymmetries not predicted by the full-adder
   equations;
5. whether any excursion satisfies relational recovery rather than scalar or
   complete-state return alone; and
6. the final classification under the frozen decision rule.

## Secondary endpoints

- transition-monoid order and composition table;
- number and type of irreversible maps;
- absorbing and reset behavior;
- F0 versus F1 state and observation distinctions;
- intervention effects on the `10` and `01` probes;
- exact covariance pass count;
- comparison with the frozen Experiment 001 positive control; and
- minimal distinguishing suffixes for every inequivalent state pair.

## Decision rule

Return `DT-0` when F0 is completely reducible to current carry or the latest
overwriting event, no full-present-matched future-divergence witness exists,
and role exchange is fully explained by the symmetric adder equations.

Return `DT-1` when additional distinctions exist but are completely reproduced
by the registered output buffer, local histories, generic memory, or other
non-relational nulls. `DT-1` denotes dissipative or buffered state transfer,
not a relational carrier.

Return `DT-2` only when at least one witness satisfies every H2 condition,
including null separation and nontrivial relational recovery. No score or
partial gate may override a failed H2 condition.

The E001 positive control is reported separately and is not used to inflate
the classification of F0 or F1.

## Falsification conditions

The claim that the canonical carry process retains history beyond its declared
state is falsified if exact behavioral minimization shows that current carry
fully determines all future output traces.

The claim of role-specific structure is falsified if exchanging `01` and `10`
preserves every complete trace as predicted by the symmetric adder equations.

The claim of relational recovery is falsified if an apparent return restores
only the carry value, or only an ordinary buffer state, without restoring a
previously demonstrated nontrivial bilateral structure.

The operational-carrier classification is falsified if any matched
non-relational null reproduces the candidate witness.

## Interpretation boundary

A `DT-0` result would identify the standard carry process as an exact
overwrite-and-propagate null for relational-history tests.

A `DT-1` result would show that ordinary finite buffering can preserve more
information than the carry projection without producing relational
irreducibility.

A `DT-2` result would justify further examination of a finite operational
carrier candidate under the registered construction only.

No result may be interpreted as evidence for Intersection Subjectivity, the
ontological completeness of a mathematical state, a historical hardware
implementation, or a physical realization not included in the frozen model.
