# Experiment 006A - Emergent Nonseparable Relational C

This result-informed confirmation separates a nonseparable second-order
interaction from two competent independent directed recall traces.

## Confirmatory result

Status: CONFIRMATORY COMPLETE

Primary readout: SUPPORTED

All ten preregistered primary checks passed on the new 48-seed allocation. The
four interacting architectures learned a bilateral inclusion-exclusion term

`C_t = H_t(ab) - H_t(a0) - H_t(0b) + H_t(00)`

that was amplified by training, transported into later joint state, affected
both receivers, and incurred a positive median cross-pair exchange cost. An
equal-capacity disconnected dual relay solved the task in all 48 seeds but had
maximum C norm `2.9323e-17`.
